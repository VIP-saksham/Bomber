## 🖥️ About

**Bomber** is a Python-based asynchronous HTTP request testing project created for **educational and authorized security research**.

The project explores how multiple HTTP requests can be handled concurrently using Python's asynchronous programming ecosystem.

> 🎓 Built for learning — not for targeting real users or disrupting third-party services.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/VIP-saksham/Bomber.git
cd Bomber
```

Install dependencies:

```bash
pip install aiohttp colorama
```

Run the project in an **authorized lab/test environment**:

```bash
python main.py
```

> The exact entry-point filename may vary depending on the current repository structure.
